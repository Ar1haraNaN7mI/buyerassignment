# Beyond Bouldering UX Redesign (React)

This project is a Vite + React website prototype aligned with assignment requirements:
- clear first-time onboarding
- lower-friction pricing comparison
- SEO-focused keyword integration
- strategic mapping from identified issues to solutions

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

1. Import the `web` folder as a project in Vercel.
2. Framework preset: `Vite`.
3. Build command: `npm run build`.
4. Output directory: `dist`.
